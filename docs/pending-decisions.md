# 나중에 결정할 것

작업 중 "나중에 결정하자"고 미뤄 둔 내용을 모아 둔다.
결정이 나면 항목을 **결정됨** 섹션으로 옮기고 결정 내용과 날짜를 적는다.

## 보류 중

### 1. 사진이 없는 코스 카드의 자리표시 모양
- 기록일: 2026-11-10 (#10 메인 화면 작업 중)
- 현재: 회색 배경 가운데에 장소 유형 아이콘 + 유형 이름("시장" 등)
- 문제: 화면이 어색하다. 아이콘 그림(`src/components/Icon.tsx`)도 단순한 선 그림이라 함께 다듬을 필요가 있다.
- 참고: "함께 가는 곳" 태그도 같은 아이콘을 쓰므로 아이콘을 바꾸면 같이 바뀐다.
- 참고: 실제 사진은 추후 한국관광공사 TourAPI로 채울 예정이라, 자리표시가 보이는 경우가 얼마나 될지도 함께 고려한다.

### 2. 메인 화면 필터를 칩으로 둘지, 검색으로 바꿀지
- 기록일: 2026-11-10 (#10 메인 화면 작업 중)
- 현재: 방송 프로그램·여행 도시 모두 좌우로 미는 칩 (각각 "전체" 포함)
- 검토 중인 안:
  - 여행 도시: 검색해서 찾기
  - 방송 프로그램: 많이 찾는 프로그램 상위 5개만 칩으로 보여주고, 나머지는 검색해서 찾기
- 고려할 점: "많이 찾는" 기준이 되는 데이터(조회 수 등)를 어디서 얻을지, 장년 사용자에게 직접 입력(검색)이 부담되지 않을지
