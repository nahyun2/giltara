작업 중 "나중에 결정하자"고 미뤄 둔 내용을 모아 둔다.
결정이 나면 항목을 **결정됨** 섹션으로 옮기고 결정 내용과 날짜를 적는다.

## 보류 중

### 1. 사진이 없는 코스 카드의 자리표시 모양
- 기록일: 2026-11-10 (#10 메인 화면 작업 중)
- 현재: 회색 배경 가운데에 장소 유형 아이콘 + 유형 이름("시장" 등)
- 문제: 화면이 어색하다. 아이콘 그림(`src/components/Icon.tsx`)도 단순한 선 그림이라 함께 다듬을 필요가 있다.
- 참고: "함께 가는 곳" 태그도 같은 아이콘을 쓰므로 아이콘을 바꾸면 같이 바뀐다.
- 참고: 실제 사진은 추후 한국관광공사 TourAPI로 채울 예정이라, 자리표시가 보이는 경우가 얼마나 될지도 함께 고려한다.

### 2. 메인 화면 필터를 칩으로 둘지, 검색으로 바꿀지
- 기록일: 2026-11-10 (#10 메인 화면 작업 중)
- 현재: 방송 프로그램·여행 도시 모두 좌우로 미는 칩 (각각 "전체" 포함)
- 검토 중인 안:
  - 여행 도시: 검색해서 찾기
  - 방송 프로그램: 많이 찾는 프로그램 상위 5개만 칩으로 보여주고, 나머지는 검색해서 찾기
- 고려할 점: "많이 찾는" 기준이 되는 데이터(조회 수 등)를 어디서 얻을지, 장년 사용자에게 직접 입력(검색)이 부담되지 않을지

### 3. 공휴일을 쉬는 날 판단에 반영할지
- 기록일: 2026-11-25 (#31 쉬는 날 반영 중)
- 현재: 공휴일 데이터가 없어 "월요일이 공휴일이면 개관/그다음 날 휴관" 같은 예외를 반영하지 못하고 원칙(쉼)대로 판단. 설·추석은 1·2·9·10월이면 "확인 필요"
- 하기로 한 것: 다음에 공휴일(설·추석 포함)을 반영하도록 작업
- 고려할 점: 공휴일 데이터 출처(공공데이터포털 특일 정보 API, 또는 연도별 날짜 목록 직접 저장), 대체공휴일 처리

## 결정됨

### 고른 날짜에 쉬는 장소를 어떻게 다룰지 (#31)
- 기록일·결정일: 2026-11-25 (Sprint 4 이슈 정리 중)
- 결정: 고른 날짜에 확실히 쉬는 장소(매주 ○요일, 1월 1일 등)는 맞춤 코스에서 빼고 "매주 ○요일에 쉬어요"를 이유로 보여준다
- 판단할 수 없는 경우는 빼지 않고 "확인 필요"로 표시
  - 설·추석(음력): 1·2·9·10월이면 확인 필요
  - "연중무휴 (단, 매주 월요일 일부 시설 휴관)": 그 요일이면 확인 필요
  - "월요일이 공휴일이면 개관" 같은 예외: 공휴일 데이터가 없어 원칙(쉼)대로 판단
- 쉬는 곳을 빼서 3곳보다 적어지면, 남은 곳을 보여주고 "이 날은 N곳만 갈 수 있어요" 안내와 "날짜 바꾸기" 버튼을 둔다
- 이유: Sprint 3에서 정한 "안 되는 게 확실한 곳만 뺀다" 원칙과 같게 함

### 휠체어·반려동물 정보가 없는 장소를 어떻게 다룰지 (#19)
- 기록일·결정일: 2026-11-24 (#19 TourAPI 정보 조회 중)
- 상황: 27곳 중 휠체어 정보 12곳, 반려동물 정보 7곳만 있음. "동반 불가"로 나온 곳은 없음
- 결정: 정보가 없는 곳은 빼지 않고 "확인 필요"로 표시하고, 전화번호가 있으면 전화 확인을 안내한다. "동반 불가"처럼 안 된다고 확실히 나온 곳만 뺀다
- 이유: 정보가 확인된 곳만 남기면 반려견을 고를 때 대부분 코스가 1~2곳이 됨
- 관련: 운주산 승마조련센터는 관광공사에 없어 같은 단지의 "운주산승마자연휴양림" 정보를 씀

### 사진이 없는 코스 카드의 자리표시 모양 → 일부 해소 (#19)
- TourAPI 사진으로 27곳 중 19곳에 사진이 생겨, 코스 대표 사진은 6개 중 4개가 사진으로 바뀜. 여수(남산공원)·아산(족욕 체험장)은 아직 자리표시라 "보류 중" 1번은 그대로 둔다

### 장소 유형을 더 만들지 (#7)
- 기록일·결정일: 2026-11-23 (#7 코스 데이터 추출 중)
- 문제: 항구(척사항), 체험 공간(족욕 체험장, 승마조련센터, 평화의 길)이 기존 5개 유형에 딱 맞지 않아 "문화유적"으로 보였다
- 결정: 유형은 5개 그대로 두고, `culture` 라벨만 "문화유적" → "문화·체험"으로 변경. 항구는 "자연"으로 분류
- 다시 볼 때: 체험 장소가 많이 쌓이거나, Sprint 3 맞춤 코스 생성에서 체험을 따로 다뤄야 하면 `experience` 유형 추가를 검토
