이번 세션의 작업을 위키에 기록해줘. 위키 저장소: ../giltara.wiki

## 순서
1. 위키 저장소에서 git pull
2. 이번 세션 대화와 커밋 내역을 바탕으로 아래 형식의 초안 작성
3. 초안을 보여주고 "AI 결과에서 직접 수정한 부분"을 나에게 물어본 뒤 반영
4. 내가 확인하면 "docs: #이슈번호 작업 기록"으로 커밋 후 push

## 프롬프트-로그.md
제목·설명 바로 아래에 추가 (기존 항목은 수정하지 않음)
### [YYYY-MM-DD] 작업 제목 (#이슈번호, PR #번호)
- 목적:
- 핵심 프롬프트: (실제 입력한 문장. 여러 번 고쳤다면 순서대로)
- 결과:
- 직접 수정한 부분:
- 프롬프트를 바꾼 이유 / 배운 점:

## 트러블슈팅.md (오류를 해결한 경우에만)
### [YYYY-MM-DD] 문제 제목 (#이슈번호)
- 문제: (오류 메시지 핵심)
- 원인:
- 해결:
- 배운 점:
- CLAUDE.md 반영: (규칙을 추가했다면)

## 규칙
- API 키, 토큰, .env 값은 절대 기록하지 않음
- 해결한 오류가 없으면 트러블슈팅은 건너뜀
